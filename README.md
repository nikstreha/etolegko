# kdfjjj11

Утилита для измерения скорости скачивания по HTTP(S). Выполняет 10
последовательных запросов к одному адресу и полностью читает каждый ответ.
Запросы асинхронные, данные читаются частями и не сохраняются на диск.

## Запуск

Нужны Python 3.14+ и [uv](https://docs.astral.sh/uv/).
Из каталога проекта выполните:

```bash
uv sync
uv run kdfjjj11 "https://example.com/image.jpg"
```

Замените адрес на ссылку на нужный файл. Справка:

```bash
uv run kdfjjj11 --help
```

## Результат

Во время скачивания в терминале обновляется одна строка: номер запроса,
прогресс, объём и скорость. Если сервер не передал размер файла, вместо
процента показывается анимация ожидания. После завершения строка исчезает.
При перенаправлении вывода в файл прогресс отключается.

Утилита выводит среднее время запроса в секундах, общий объём скачанных
данных в байтах и MiB, скорость в MiB/s. 1 MiB = 1 048 576 байт.

Среднее время — сумма времени запросов, делённая на 10.
Скорость — общий объём, делённый на суммарное время запросов.
Время включает ожидание сервера, перенаправления и чтение тела ответа.
Объём учитывает тела конечных ответов до распаковки Content-Encoding,
без HTTP-заголовков.

Тайм-аут подключения и ожидания очередной порции данных — 60 секунд.
При сетевой или HTTP-ошибке выполнение прекращается с кодом 1,
при некорректном адресе — с кодом 2.
